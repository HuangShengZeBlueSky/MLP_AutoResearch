## 🏆 最佳发现 (最新精度: 0.9836)

通过 AI Agent 的自主约束变体和实验（限定只能调整 `train.py` 中的架构和各种超参数），我们发现对于 MNIST 数据集（20个 epochs 时），盲目加深网络（如最初定义的 20 层深度 MLP）并不是最优解。AI 最终通过探索锁定在了一个**更浅更宽并配合强正则化**的架构：

1. **改进方向一（网络架构）：宽度比深度更重要**
   网络从复杂的 20 层深层网络退回到 3 层。隐藏层节点从 256 增加到 512 维。参数量 935,434，有效防止了梯度消失问题。
2. **改进方向二（激活函数）：GELU 替代 ReLU**
   平滑的非线性激活 GELU 在训练过程中展现了比 ReLU 更好的收敛特征和更高的精度天花板。
3. **改进方向三（优化器与调度）：AdamW + Cosine Annealing + Weight Decay**
   Agent 放弃了传统的恒定学习率 Adam/SGD，加入了 Cosine 余弦退火学习率，并配合 $1e-4$ 的 Weight Decay（权重衰减）和 $0.1$ 的 Dropout，在极其有效的防止过拟合的同时，在最后几个 epoch 将准确率榨取到了极限。
